## 編集方針

- すべて **公的な一次資料**（中期経営計画 / 統合報告書 / 適時開示 / 決算短信）に基づく
- **推測値は含めない**。公開情報で確認できない項目は「公開情報からは不明」と明記
- 各社末尾の参照リンクから最新の原資料を確認可能

## 技術スタック

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- 静的サイト生成 (SSG) — 全 19 ページ プリレンダリング

## ローカル開発

```bash
npm install
npm run dev
# http://localhost:3000
```

## Vercel へのデプロイ

最も簡単な方法は Vercel ダッシュボードからの GitHub 連携です。

1. <https://vercel.com/new> にアクセス
2. GitHub の `tarookudasygk-prog/20260511_test` リポジトリを Import
3. Branch を `claude/ip-character-encyclopedia-OZdgc` （または `main`）を指定
4. Framework Preset は **Next.js** が自動検出される
5. **Deploy** をクリック

すべてデフォルト設定で動作します（環境変数・カスタム設定不要）。デプロイ完了後、`https://<project-name>.vercel.app` の形式で公開URLが発行されます。

または Vercel CLI:

```bash
npm i -g vercel
vercel
```
